# Объединение ПР3 и ПР4

Источник ПР3: https://github.com/kuzyaa1/up04.01_pr3, коммит `6ca1215`.
Результат: `UP2/library_web`.

Из ПР3 перенесены модели и демонстрационные данные, точная валидация дат,
формы и исправленный множественный выбор, защита несохранённого ввода,
карточки просмотра пяти сущностей, синхронизация фильтров с URL,
безопасные неизвестные фильтры, исправленная таблица, локальные репозитории
с проверками связей и миграцией, схемы и регрессионные тесты.

Рабочее приложение использует API ПР4; локальные реализации ПР3 сохранены
для тестов. История GitHub не менялась, кэши исходного проекта не переносились.

API дополнен правилами уникальности, зависимостей и восстановлений ПР3.
Исправлены потеря почты брони и заметок клиента, связи фотографов с залами,
счётчики бронирований, серверная сортировка имён, полные справочники,
повторная отправка после 422 и сетевые ошибки форм. Дата брони передаётся
как календарный день, чтобы часовой пояс не сдвигал её.

Экраны объединены с сетевыми состояниями, правами и блокировкой сохранения;
вёрстка и валидация ПР3 сохранены. Роутер объединяет карточки и `onExit`
ПР3 с входом и ролями ПР4. Правила целостности перенесены на сервер.

Резерв исходного кода, тестов, сервера и документации до изменений:
`.audit_pr4/before.zip`. Сборочные кэши в архив не включены.

Итог проверки: 106 тестов Flutter и 90 проверок API пройдены,
`flutter analyze` не нашёл замечаний, `flutter build web` выполнен успешно.
В браузере проверены список из API, пустой поиск, недоступность сервера,
загрузка с задержкой и повтор после восстановления, а также сбой CORS
из-за неверного origin и его устранение. Снимки — в `docs/screenshots`.

Для полного комплекта сдачи отдельно остаются снимки 422/409 и Network,
а также публикация ПР4 в репозитории. Эти материалы не выдаются за готовые.
